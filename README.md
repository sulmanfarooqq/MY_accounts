# Flutter + Supabase Authentication

A focused Flutter project exploring **Supabase authentication** and account-management flows.

## Highlights

- Flutter-based mobile UI
- Supabase authentication integration
- Account sign-in flow experimentation
- Practical exploration of client/backend authentication boundaries

## Tech Stack

- Flutter
- Dart
- Supabase

## Run Locally

```bash
flutter pub get
flutter run
```

Configure your own Supabase project credentials through the project's supported configuration method. Do not commit private service credentials.

## Purpose

This repository is an experimental authentication project used to understand how Flutter applications integrate with a hosted authentication backend.
